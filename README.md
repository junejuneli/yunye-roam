# 云野漫游

单文件 HTML 的 3D 开放世界探索游戏。电脑和手机浏览器打开 `index.html` 就能玩，不需要安装任何东西。

一座岛，三位可以随时切换的旅人，四座等着被点亮的风塔。

## 怎么玩

| | 电脑 | 手机 |
|---|---|---|
| 移动 | WASD | 左半屏拖动 |
| 视角 | 点击画面后移动鼠标（或按住拖动），滚轮远近 | 右半屏拖动 |
| 跳 / 滑翔 | 空格（青岚在空中按住） | 「跳」键 |
| 跑 | Shift | 「跑」开关 |
| 攻击 | J 或鼠标左键 | 「攻」键 |
| 技能 | K / E / 鼠标右键 | 技能键 |
| 换人 | 1 2 3 或 Q | 角色头像 |
| 菜单 | P / Esc | ☰ |

| 角色 | 定位 | 普攻 | 技能 |
|---|---|---|---|
| 赤羽 | 剑士 | 三段连斩 | 冲刺斩：突进伤敌，撞碎有裂纹的岩石 |
| 青岚 | 风行者 | 风刃；二段跳，空中按住跳跃滑翔 | 乘风：把自己送上高空；滑进上升气流会被托起 |
| 霜月 | 术士 | 自动追敌的冰锥 | 霜华：冻住周围敌人，之后 12 秒踏水成冰 |

- 星辉 48 枚，每 12 枚体力上限 +20
- 宝箱 20 个，每 4 枚心之碎片 +1 颗心
- 点亮风塔 +1 颗心，成为复活点，小地图显示附近宝物
- 四塔全亮后有结局，此后夜空出现极光

进度自动存在浏览器本地（localStorage）。

## 开发

```bash
python3 build.py        # src/ → index.html
python3 build.py test   # src/ → test.html（用模拟引擎，不需要联网）
python3 tools/smoke_test.py   # 需要 playwright + Chrome，跑一整轮游玩流程
```

源码按加载顺序拆在 `src/`：

| 文件 | 内容 |
|---|---|
| `head.html` | 页面结构与样式（界面、标题、菜单） |
| `00_shaders.js` | 天空、水面、上升气流、粒子的着色器 |
| `01_core.js` | 噪声、地形高度、压平工具 |
| `02_engine.js` | 渲染器、光照、画质档位、随风摆动材质 |
| `03_world.js` | 世界布局、地形网格、水面、天空与昼夜 |
| `04_nature.js` | 碰撞体与平台、树、石头、草、花 |
| `05_fx.js` | 粒子、环境粒子、刀光与冲击环 |
| `06_objects.js` | 石台、浮岛、风塔、宝箱、裂岩、星辉 |
| `07_actors.js` | 三位角色与敌人的模型 |
| `08_game.js` | 敌人 AI、战斗、技能、角色控制、收集与提示 |
| `09_hud.js` | 生命、体力、提示、小地图 |
| `10_main.js` | 声音合成、存档、输入、菜单、镜头、主循环 |

依赖只有 Three.js r128（从 cdnjs 加载）。模型全部用代码生成，声音全部现场合成，没有任何图片或音频文件。

## 已知情况

- 游戏逻辑用模拟引擎做过完整流程测试，着色器在 WebGL1/2 下编译通过。
- 角色模型、树木和草地的实际观感与真机帧率还需要更多实机反馈。
