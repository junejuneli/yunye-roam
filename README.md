# 云野漫游

单文件 HTML 的 3D 开放世界探索游戏。电脑和手机浏览器打开 `index.html` 就能玩，不需要安装任何东西。

一座岛，三位可以随时切换的旅人，四座等着被点亮的风塔。

## 怎么玩

| | 电脑 | 手机 |
|---|---|---|
| 移动 | WASD | 左半屏拖动 |
| 视角 | 点击画面后移动鼠标（或按住拖动），滚轮远近 | 右半屏拖动 |
| 跳 / 滑翔 | 空格（青岚在空中按住） | 「跳」键 |
| 跑 | Shift | 「跑」开关 |
| 攻击 | J 或鼠标左键 | 「攻」键 |
| 技能 | K / E / 鼠标右键 | 技能键 |
| 大招 | R / F（充能满后） | 大招键 |
| 换人 | 1 2 3 或 Q | 角色头像 |
| 地图 / 菜单 | M / P、Esc | 小地图、☰ |

| 角色 | 普攻 | 技能 | 大招 |
|---|---|---|---|
| 赤羽 · 剑士 | 三段连斩，第三段是重击 | 冲刺斩：突进伤敌，撞碎裂岩，破开石甲 | 燎原：原地回旋三斩 |
| 青岚 · 风行者 | 风刃；二段跳，空中按住跳跃滑翔 | 乘风：升空，掀飞敌人，吹落风蝠 | 风眼：把敌人卷到一起的龙卷，也是一股能乘的上升气流 |
| 霜月 · 术士 | 自动追敌的冰锥 | 霜华：冻住周围敌人，之后 12 秒踏水成冰 | 霜天：持续冻结一片范围，水面结冰 |

技能之间的联动：

- **碎冰**：冻住的敌人被重击、冲刺斩或燎原打中，伤害翻倍
- **扩散**：乘风卷到冻住的敌人，会把冻结传给周围
- **追击**：被吹上天或吹落在地的敌人多受五成伤害
- **接力**：放完技能立刻换人，接下来 6 秒伤害提高五成
- **破甲**：岩傀和霜卫的甲只有冲刺斩和燎原能破，破甲后它们会瘫倒几秒

| 敌人 | 特点 | 弱点 |
|---|---|---|
| 草 / 水史莱姆 | 蹦跳撞人 | 水史莱姆冻得更久 |
| 炎史莱姆 | 落地溅火，燃烧着倒下会爆炸 | 冰能浇灭它，伤害翻倍 |
| 风蝠 | 盘旋后俯冲，剑够不着 | 风刃双倍伤害，乘风能吹落 |
| 幽火 | 远程火球，近身会闪开 | 冻住就闪不掉 |
| 岩傀 | 石甲格挡，砸地前地上亮红圈 | 冲刺斩破甲 |
| 史莱姆王 | 守着林隐之塔，落地冲击波，半血分裂 | 先冻再碎冰 |
| 霜卫（首领） | 守着霜顶之塔：砸地、冰锥齐射、落冰，不能被冻结 | 破甲后全力输出 |

- 星辉 48 枚，每 12 枚体力上限 +20
- 宝箱 20 个，每 4 枚心之碎片 +1 颗心
- 点亮风塔 +1 颗心，成为复活点，小地图显示附近宝物
- 霜顶之塔被冰封着，打倒霜卫才会解封
- 四塔全亮后有结局，此后夜空出现极光

进度自动存在浏览器本地（localStorage）。菜单里有图鉴、操作说明，以及音量、画质、视角灵敏度等设置。

## 上线

`index.html` 是完整的成品：Three.js 已经内联在里面，不请求任何外部资源。把这一个文件放到任意静态托管（GitHub Pages、Vercel、对象存储、自己的服务器）就能访问。

## 开发

```bash
python3 build.py        # src/ + vendor/three.min.js → index.html（上线用）
python3 build.py test   # → test.html，用模拟引擎
node tools/smoke_test.js          # 跑一整轮游玩流程（需要 playwright）
python3 build.py dev    # → dev.html，真引擎 + 调试接口 window.__g
node tools/shot.js 场景脚本.js     # 无头浏览器截图，看实际画面
```

改了 `src/` 之后要重新运行 `python3 build.py`，不要直接改 `index.html`。

源码按加载顺序拆在 `src/`：

| 文件 | 内容 |
|---|---|
| `head.html` | 页面结构与样式（界面、标题、菜单、地图、结局） |
| `00_shaders.js` | 天空、水面、上升气流、粒子的着色器 |
| `01_core.js` | 噪声、地形高度、压平工具 |
| `02_engine.js` | 渲染器、光照、画质档位、随风摆动材质 |
| `03_world.js` | 世界布局、地形网格、水面、天空与昼夜 |
| `04_nature.js` | 碰撞体与平台、树、石头、草、花 |
| `05_fx.js` | 粒子、环境粒子、刀光与冲击环 |
| `06_objects.js` | 石台、浮岛、风塔、宝箱、裂岩、星辉 |
| `07_actors.js` | 三位角色与全部敌人的模型（描边、画布贴脸、发束） |
| `08_game.js` | 敌人 AI、预警圈、战斗与联动、大招、角色控制、收集与提示 |
| `09_hud.js` | 头像、生命、技能键、飘字、首领血条、目标、地图、图鉴 |
| `10_main.js` | 声音合成、存档、输入、菜单、镜头、主循环 |

依赖只有 Three.js r128（MIT，放在 `vendor/`）。模型全部用代码生成，声音全部现场合成，没有任何图片或音频文件。

## 已知情况

- 游戏逻辑有完整流程的自动测试；画面在无头浏览器的软件渲染下逐项截图检查过。
